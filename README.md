\# 竞赛赛题追踪与学习路径生成系统



基于 OpenClaw 多智能体 + 知识图谱 + 大模型的竞赛服务平台。



\## 核心功能



\- 赛题实时追踪（已采集蓝桥杯 8398 道赛题）

\- 赛题解析（大模型抽取知识点 + 前置依赖关系）

\- 知识图谱构建（Neo4j：竞赛-赛题-知识点-技能）

\- 学习路径动态生成

\- 变更监测



\## 技术栈



| 层次 | 技术 |

|---|---|

| 多智能体框架 | OpenClaw |

| 后端 | FastAPI + Python |

| 图数据库 | Neo4j 5.26 |

| 前端 | Vue3 + Vite |

| 大模型 | DeepSeek API |

| 部署 | 阿里云 ECS + Nginx |
